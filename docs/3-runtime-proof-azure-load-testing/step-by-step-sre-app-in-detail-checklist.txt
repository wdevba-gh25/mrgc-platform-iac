SECTION G - WHY THE DOCKERFILE FIX MATTERED
Problem:
- package.json correctly preloaded instrumentation.js
- but Dockerfile bypassed npm start by calling node src/server.js directly
- therefore instrumentation.js never loaded inside AKS
- backend was healthy, but telemetry did not appear

Fix:
- Dockerfile changed to:
  - CMD ["npm", "start"]

Result:
- container used package.json startup script
- instrumentation.js loaded before server.js
- Application Insights initialized inside AKS

- DONE
