----------------------------------------------------------------------
S.0 - CRITICAL MENTAL MODEL
----------------------------------------------------------------------

ACR image tags and Kubernetes deployments are different things.

ACR stores images:
- repository + tag = available image version

Kubernetes runs images:
- `kubectl apply` sends YAML to AKS
- AKS reads the image reference from YAML
- AKS pulls that image from ACR
- AKS creates pods

If Kubernetes YAML references `qa-v1`, ACR must already contain `qa-v1`.
